# 刘乃嘉 · 悦为体品牌渠道负责人 入职营销方案

**入职日期**：2026年4月13日（周一）  
**岗位**：品牌渠道负责人  
**核心阵地**：小红书（偏重）+ 多平台协同  
**品牌阶段**：初创期时尚饰品&潮玩品牌

---

## 一、第一周：看清楚再动手（调研周）

> 原则：不急着输出内容，先建立信息底座。新品牌最怕的是方向跑偏之后才发现。

### Day 1-2：内部信息采集

**要找到的文件/答案**：

- 品牌Story：创始人为什么做这个品牌？核心信念是什么？
- 现有产品线：SKU数量、主推款、定价区间、毛利结构（大概了解）
- 已有渠道现状：小红书账号粉丝/笔记数、抖音、天猫/淘宝店铺状态
- 外部团队情况：正在合作的MCN/代理商/达人有哪些？合同周期？
- 历史数据：过去跑过的内容中，哪几篇数据最好？为什么？
- 竞争对手：老板心中认为哪些品牌是竞品？

**行动**：

- [ ] 与创始人/老板进行1小时深度对谈（准备10个问题，见下方问题清单）
- [ ] 收集所有已有品牌素材：logo、产品图、VI规范、历史文案
- [ ] 加入所有内部群，观察沟通风格和决策链条

### Day 3-4：竞品与平台调研

**小红书竞品分析（每个竞品看以下维度）**：

| 维度 | 要记录的内容 |
|------|------------|
| 账号粉丝/点赞收藏比 | 判断内容质量vs涨粉效率 |
| 爆文类型 | 产品展示/生活方式/教程/情感 |
| 评论区高频词 | 用户真实需求和痛点 |
| 达人合作风格 | 硬广/软植/测评/剧情 |
| 发布频率 | 工作日/周末规律 |

**重点对标3-5个品牌**，做成竞品矩阵表格。

### Day 5：整理洞察，提出第一版方向假设

- 输出一份**品牌现状诊断备忘录**（内部文档，非对外）
- 列出你认为的：3个机会点 + 2个风险点
- 约老板/核心团队做15分钟对齐

## 二、第一个月（4月13日 - 5月9日）：夯实基础

### 1. 品牌DNA文档建立

这是后续所有内容的"宪法"，必须先做：

```
品牌DNA文档包含：
├── 品牌主张（1句话）
├── 目标用户画像（主力人群 + 潜力人群）
├── 品牌人格（5个形容词）
├── 内容语气词典（鼓励用词 / 禁止用词）
├── 视觉风格关键词（3-5个）
└── 内容选题禁区
```

**产出物**：一份可共享给外部团队的《品牌内容手册》（1.0版，5-8页即可）

### 2. 小红书账号诊断与内容规划

**账号诊断要看**：
- 账号标签是否精准（用薯条/笔记助推测试）
- 主页首图/置顶笔记是否形成转化漏斗
- 关键词布局：标题/正文/话题标签是否覆盖搜索词

**第一个月内容节奏**（建议）：

| 内容类型 | 频率 | 目标 |
|--------|------|------|
| 产品故事/设计师日记 | 2篇/周 | 建立品牌温度 |
| 穿搭/使用场景展示 | 2篇/周 | 种草转化 |
| UGC转发+互动 | 日常 | 激活粉丝关系 |
| 话题互动笔记 | 1篇/周 | 提升互动率 |

### 3. 建立外部团队协作机制

你的岗位核心之一是**监督和对接外部团队**，需要快速建立：

- **内容Brief模板**：每次给外部团队的创作需求文档，包含：目标/人群/核心信息/禁忌/参考案例/交付格式
- **数据复盘节奏**：每周固定时间（建议周五下午）看上周数据，外部团队必须提交周报
- **内容审核流程**：脚本→初稿→终稿，明确每个环节你的审核时间SLA

### 4. 用户反馈收集系统

建立一个简单的**用户声音文档**（飞书/腾讯文档均可）：

- 每天15分钟：扫描小红书评论、私信、竞品评论区
- 记录高频关键词、抱怨点、期待
- 每两周汇总一次，同步给产品/设计团队

## 三、第二个月（5月12日 - 6月6日）：放大有效信号

### 快速验证内容方向

用第一个月的数据，找到**哪类内容点赞收藏比最高**，加大这类内容的产出比例。

**判断标准**：
- 收藏率 > 5%：内容有参考价值，值得复制
- 评论中出现"在哪买" / "链接" / "多少钱"：直接转化意图强
- 转发率高：情感共鸣强，适合做品牌认知

### KOL/KOC矩阵搭建

根据你的历史经验，建议分三层：

| 层级 | 量级 | 目标 | 预算占比 |
|------|------|------|---------|
| KOC素人 | 1K-1W粉 | 铺量/真实口碑 | 40% |
| 腰部KOL | 1W-50W粉 | 种草效率 | 45% |
| 头部KOL | 50W+ | 品牌曝光 | 15% |

**达人筛选核心指标**：
- 粉丝画像与目标用户重合度（>60%）
- 近30天互动率（小红书建议 >3%）
- 评论区真实度（看是否有真实讨论）
- 历史合作品牌调性是否冲突

### 小红书搜索词布局

时尚饰品类搜索词分层：

```
需求词（高流量）：耳环推荐、小众饰品、穿搭配饰
场景词（中流量）：约会耳环、气质颈链、通勤饰品
人群词（精准）：显脸小耳环、秋冬饰品穿搭
品牌词（长期）：[品牌名]测评、[品牌名]值得买吗
```

每篇笔记选题时，有意识地覆盖不同层级词。

## 四、第三个月（6月9日 - 7月4日）：建立可持续运营体系

### 内容日历制度化

- 建立**月度内容日历**（提前4周规划）
- 结合节假日/营销节点/品牌自造节点
- 外部团队按日历交稿，你按节点审核发布

**2026年Q2-Q3关键营销节点**：
- 5月20日（520）：情感/礼物场景
- 6月1日（儿童节）：潮玩品类机会
- 6月18日（618）：促销种草提前2周启动
- 7月7日（七夕）：提前6周布局

### 数据看板建立

建议用飞书多维表格或腾讯文档，每周更新：

| 指标 | 频率 | 目标值（参考） |
|------|------|-------------|
| 小红书粉丝净增 | 周 | 根据基数定 |
| 笔记平均互动率 | 周 | >3% |
| 搜索词排名 | 月 | 核心词TOP20 |
| KOL合作ROI | 每次合作后 | >1:3 |
| UGC数量 | 月 | 环比+20% |

### 品牌资产沉淀

- 整理**达人数据库**：合作过的达人、报价、效果、续合作意向
- 整理**爆款内容库**：哪些选题/格式/拍摄风格跑出来了
- 整理**用户评价库**：正面评价用于内容/详情页素材

## 五、第一周老板沟通问题清单

入职第一天或第二天，建议和老板/创始人确认：

1. **品牌定位**：我们想成为什么品牌？3年后希望用户怎么描述我们？
2. **目标用户**：最核心的目标用户是谁？有没有已购买用户可以访谈？
3. **成功标准**：我的岗位在第3个月/第6个月，什么指标代表"做得好"？
4. **预算情况**：KOL合作预算、内容制作预算大概是多少？
5. **决策链条**：内容发出前需要谁审核？审核周期是多久？
6. **外部团队**：现在在合作哪些团队？我是否有权调整合作？
7. **竞品认知**：你最担心哪个竞品？你最欣赏哪个品牌（不限行业）？
8. **产品节奏**：接下来3个月有哪些新品上线计划？
9. **禁区**：有没有内容/合作方向是绝对不能碰的？
10. **资源支持**：我需要摄影资源时，内部还是外包？

## 六、30天快速建立信任的关键动作

基于你8年经验，这些动作能让你快速展现价值：

### 快赢动作（2周内可完成）

- [ ] 输出竞品分析报告（3-5个品牌，有图有数据）
- [ ] 优化小红书账号主页（置顶笔记、简介、高亮）
- [ ] 建立外部团队Brief模板，发给现有合作团队
- [ ] 找到1-2个低成本KOC合作机会，快速测试内容方向

### 建立专业形象

- 每周固定输出**一页数据洞察**给老板（不超过5个指标，有结论）
- 遇到不确定的事，先给方案和选项，再问决策，不要空手来问
- 主动同步进度，让团队知道你在推进什么

## 七、注意风险提示

**初创品牌常见坑，提前规避**：

1. **DNA未定就大量产内容**：内容风格不统一，积累的粉丝不精准
2. **过度依赖外部团队**：品牌声音失控，复盘时说不清楚数据
3. **追热点但丢品牌调性**：短期数据好但伤害品牌长期认知
4. **数据只看粉丝数**：初创期更看重互动质量和转化意图
5. **内容和产品节奏脱节**：种草内容发出去，产品断货或详情页未优化
